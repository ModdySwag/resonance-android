> Play's current Store listing experiments test **descriptions and graphics**, not the app name, and allow the current listing plus up to two variants. ## 4. A/B test plan

**Arms.** A is the control (current listing). B and C are the two challengers. Play's experiment tool accepts the current listing plus up to two variants, which fits exactly.

**What can actually be tested.** The current Console experiment flow offers the short description, full description, icon, feature graphic and screenshots. It does **not** offer the app name. So:

1. **Short-description experiment (the clean test).** Keep the title on A. Run A’s short description against B’s and C’s. This isolates the keyword lead from the brand.
2. **Title test (the package test).** Create custom store listings that use the full B and C packages (title + short description), targeted at the countries where each term leads: B for the US and UK, C for Australia, A as the default elsewhere. Custom listings support a different app name, so this is the supported route. Treat the result as market-level evidence, not a randomised test: the countries differ in more than the title.
3. If you would rather not run both, run the short-description experiment first. It is the cheaper, cleaner signal, and the short description carries the same words.

**Hold everything else constant.** Same icon, feature graphic, screenshots, category, price and full description in every arm. One change at a time is the only way to know what moved.

**Duration and metric.** Let Play run until it reports a result (the Console estimates the time and traffic it needs); do not stop at the first good week. Use the experiment's install metric as the primary result, not impressions. A 14-day minimum is a reasonable floor, but “more data needed” means wait.

**Read it by market.** The research is market-specific: brown noise leads in the US and UK, white noise in Australia. If the Console gives a country breakdown, read the result per market before choosing one global title.

**Do not chase.** “sleep sounds” is the biggest worldwide term in the research (63.3 vs 40.5 for “binaural beats”), but it is owned by Calm, Headspace, BetterSleep and Endel. “tinnitus relief” is a health claim and is off-limits for this listing. Neither belongs in the title or short description.

## 8. Phrases to keep out

- **Treatment claims:** “treats insomnia”, “cures anxiety”, “helps depression”, “relieves tinnitus”, “clinically proven”, “therapy”, “heals”. The app is not a medical device.
- **Rankings:** any claim to be the top app, number one, or the world’s most popular. There is no evidence for them and Play does not need them.
- **False absolutes:** “completely free” (there is an optional unlock), “no in-app purchases” (there are), “no permissions” (there are five), “works on every device” (it needs a working WebView).
- **Keyword stuffing:** the title and short description above are sentences. Do not add a comma-separated keyword tail.
